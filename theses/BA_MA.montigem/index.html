MontiGem – Model-Driven Generation of Web Applications

MontiGem is a low-code generator framework that produces complete, deployable web applications from models. Developers describe the data structure with UML/P class diagrams, the user interface with a GUI DSL, and validation rules with OCL. From these models, MontiGem generates a full-stack application: a Spring Boot backend, an Angular frontend, persistence (e.g., PostgreSQL or Neo4j), and the communication between them. Handwritten code is integrated seamlessly via the TOP mechanism, so applications can be regenerated at any time while models and handwritten extensions co-evolve.

MontiGem is not only a research prototype: it is used in real-world projects, e.g., for financial management, digital twin cockpits, and assistive systems. More background is available on the MontiGem website and on our MontiGem research page.

While MontiGem already covers the core of data-centric applications, many exciting questions remain open. We offer bachelor and master thesis topics around the MontiGem generator, for example:

  • Language Engineering: Extending the GUI DSL or the class diagram language with new concepts, components, and well-formedness checks.
  • Generator Engineering: Generating additional functionality such as authentication, roles and permissions, or new GUI components and visualizations.
  • Persistence & Infrastructure: Supporting further database technologies, deployment scenarios, or performance optimizations of the generated code.
  • Model-Based Testing: Generating tests from models and improving the quality assurance of generated applications.
  • Model-Driven GUI Generation: Automatically deriving user interfaces from class diagrams (e.g., CD2GUI).
  • AI & MontiGem: Using LLMs to assist in creating, completing, or validating MontiGem models.

Your Profile

  • Current Studies: Bachelor’s or Master’s student in Computer Science, or a closely related field.
  • Programming: Good programming skills in Java; experience with TypeScript/Angular or Spring Boot is a plus.
  • Modeling: Interest in modeling languages and code generation; knowledge of UML class diagrams is helpful.
  • Lectures: It is very helpful to have attended the lectures SLE or MBSSE, especially SLE.
  • Mindset: Motivated, proactive, and independent. You are ready to contribute your own ideas, not just implement predefined tasks.
  • Communication: Good communication skills in German or English.
  • Readiness to Learn: Ability to quickly grasp new technologies, specifically:
    • The MontiGem generator framework and its architecture
    • The MontiGem GUI-DSL for describing user interfaces
    • The modeling languages used as input, i.e., UML/P class diagrams and OCL
    • Template-based code generation with FreeMarker (especially relevant for CD2GUI topics)
    • Build tools and infrastructure (e.g., Gradle, Docker, GitLab CI/CD)

What We Offer

  • Practical Relevance: Your work becomes part of a generator framework that is used in real-world applications.
  • Full-Stack Experience: Gain hands-on experience with modern web technologies as well as model-driven software engineering.
  • Close Supervision: Regular meetings and hands-on guidance throughout your thesis.
  • Publication: For particularly good results, we aim for an academic publication together.

How to Apply

For more information or to apply, please send your application documents (CV, Transcript of Records, and a short motivation statement) to: Sebastian Will 📧 will@se-rwth.de

Depending on the topic, the thesis will be supervised by a member of the MontiGem team. We define the exact scope together with you, if you already have preferences, you can say so in your application documents.
